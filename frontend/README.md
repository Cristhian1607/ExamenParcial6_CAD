# Cliente Angular

La interfaz del proyecto **Agenda clara** consume la API REST alojada en `../backend`.

Desde esta carpeta:

```powershell
npm install
npm start
```

La aplicación se sirve en `http://localhost:4200` y reenvía `/api` a `http://localhost:5175`. Consulta el [README principal](../README.md) para configurar MongoDB Atlas, iniciar el backend y revisar los endpoints.
